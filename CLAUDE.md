# Working agreements

- After making code changes in this repo, commit and push to `origin/main` without asking
  for confirmation first. The user has pre-authorized this standing behavior (2026-08-20).
  Pushing to `main` triggers auto-deploy on both Railway (backend) and Vercel (frontend).
- Still use judgment: skip the auto-push for work-in-progress the user asked to keep local,
  and never force-push or rewrite history without asking.
